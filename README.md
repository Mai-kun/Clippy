# 📎 Clippy

> **Сверхлёгкий, бескомпромиссный instant replay рекордер для Windows.**  
> Замена GeForce Experience / ShadowPlay и Medal без гигабайтов Electron, без обязательных аккаунтов, рекламы и фоновой нагрузки на процессор.

### 🎯 В чём главная фишка Clippy?

Большинство современных игровых рекордеров (Medal, Outplayed) построены на базе Electron: они весят по 300–500 МБ, съедают до 1.5–2 ГБ оперативной памяти и отбирают ценные кадры/с в играх. ShadowPlay требует отдельного софта NVIDIA, принудительного входа в аккаунт и перегружен фоновыми службами телеметрии.

**Clippy решает эту задачу с точки зрения системной оптимизации:**
* 🚀 **0.2% CPU и 0-copy в VRAM:** Кадр рабочего стола из `Windows.Graphics.Capture` передаётся напрямую в аппаратный чип NVENC в памяти видеокарты, полностью исключая прокачку сотен мегабайт в секунду через процессор и шину PCIe.
* 📦 **Сверхкомпактный размер (~8 МБ):** Полностью нативный исполняемый файл (Native AOT) без зависимостей от установленного .NET Runtime. Архив релиза весит всего ~4 МБ.
* 🧠 **Двухуровневый гибридный буфер:** Свежие 32 секунды хранятся в RAM, а длинный 3-минутный хвост сбрасывается в кэш на SSD — потребление памяти процесса стабильно зафиксировано на уровне ~50–120 МБ.
* 🎬 **Аппаратный HEVC (H.265) из коробки:** Трёхминутный ролик в отличном качестве весит всего ~60 МБ.
* 🎧 **Эталонная A/V-синхронизация:** Задержка звука зафиксирована на эталонных -15…-20 мс с дрейфом ровно 0.0 мс на любых дистанциях записи.
* 🪟 **Чистый фоновый запуск:** Никаких мелькающих черных окон консоли — приложение запускается сразу в системный трей, управляется горячими клавишами (F8 / F9) и присылает нативные тосты Windows.

## Быстрый старт

Есть три простых способа установки:

### 1. Через Windows Package Manager (Рекомендуется)

```powershell
winget install Mai-kun.Clippy
```

Менеджер пакетов Windows сам скачает актуальный инсталлятор, установит Clippy для текущего пользователя и позволит обновлять программу одной командой: `winget upgrade Mai-kun.Clippy`.

### 2. Установщик (`Clippy-Setup.exe`)
Скачайте `Clippy-Setup.exe` из [раздела релизов](https://github.com/Mai-kun/Clippy/releases). Установщик не требует прав администратора, ставит программу в `AppData\Local\Programs\Clippy`, добавляет ярлык в меню «Пуск», опциональный автозапуск с Windows и поддерживает тихое обновление в 1 клик.

### 3. Портативная версия (`Clippy-win-x64.zip`)
Распакуйте архив в любую удобную папку и запустите `Clippy.exe`.

> `ffmpeg.exe` **не требуется** в поставке: благодаря прямому доступу к аппаратному чипу NVENC (`clippy_nvenc.dll`) и системному кодированию звука через Windows Media Foundation, Clippy полностью автономен из коробки. При необходимости фолбэка на сторонний ffmpeg (например, для видеокарт AMD/Intel) достаточно положить `ffmpeg.exe` рядом или иметь его в системном PATH.

После запуска Clippy тихо появится в системном трее рядом с часами. Запускайте любую игру — нажмите **F8** сразу после зрелищного момента, чтобы сохранить последние 30 секунд, или **F9**, чтобы сохранить последние 3 минуты.

Завершение работы: правый клик по иконке в трее → **Exit**.

### Горячие клавиши

| Клавиша | Действие | Длительность по умолчанию |
|---|---|---|
| **F8** | сохранить короткий клип | 30 секунд |
| **F9** | сохранить длинный клип | 3 минуты |

Клавиши можно переназначить независимо прямо через контекстное меню трея (F1–F12, NumPad 0–9) или через файл `config.json`. Горячие клавиши глобальные и работают поверх любых полноэкранных игр.

После сохранения клипа Clippy воспроизводит короткий системный звуковой сигнал в наушники и показывает нативное всплывающее уведомление Windows Toast с именем сохранённого файла.

## Настройки: `config.json`

Рядом с `Clippy.exe` находится файл `config.example.json` — образец настроек с подробными комментариями на русском языке. Скопируйте его в `config.json` для ручного тюнинга.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `OutputFolder` | `clips` | Папка для сохранения готовых клипов |
| `LogsFolder` | `logs` | Папка для отладочных логов (хранятся последние 10 сессий) |
| `ShortClipSeconds` | `30` | Длительность короткого клипа (по F8) |
| `LongClipSeconds` | `180` | Длительность длинного клипа (по F9) |
| `ShortClipHotkey` | `F8` | Горячая клавиша короткого клипа (F1–F12, NumPad 0–9) |
| `LongClipHotkey` | `F9` | Горячая клавиша длинного клипа (F1–F12, NumPad 0–9) |
| `PlaySoundNotification` | `true` | Звуковой сигнал в наушники при сохранении |
| `CustomSoundPath` | `""` | Свой звук уведомления (`.wav`); пусто = системный звук Windows |
| `StartMinimizedToTray` | `true` | Запуск сразу в системный трей без окна консоли |
| `CheckForUpdates` | `true` | Фоновая проверка обновлений на GitHub при старте |
| `VideoEncoder` | `nvenc_direct` | Энкодер: `nvenc_direct` (0-copy VRAM) / `h264_nvenc` / `libx264` |
| `VideoCodec` | `hevc` | Видеокодек: `hevc` (H.265, в 2 раза эффективнее) / `h264` |
| `VideoBitrateMbps` | `6` | Целевой битрейт видео в Мбит/с (диапазон 2–50) |
| `MaxClipsFolderSizeGB` | `0` | Лимит диска для клипов, ГБ. `0` = без лимита (10 / 20 / 30 / 50) |
| `AudioEncoder` | `media_foundation` | Аудиокодек: `media_foundation` (системный AAC Windows) / `ffmpeg` |

### Защита диска от переполнения

У папки с клипами есть защита от случайного заполнения накопителя: пункт **Clips Storage Limit** в трее или параметр `MaxClipsFolderSizeGB` в файле конфигурации.

После каждого сохранения клипа размер папки проверяется: если суммарный объём превышает заданную квоту, самые старые клипы автоматически удаляются по принципу FIFO. Удаляются исключительно файлы `*.mp4`, любые посторонние файлы не затрагиваются. По умолчанию квота отключена (`0`).

Клип сохраняется **строго** по нажатию горячей клавиши. При выходе из программы (Exit в меню трея) Clippy ничего лишнего не сохраняет и сразу освобождает ресурсы.

### Архитектура памяти и битрейт

Clippy непрерывно хранит историю за последние 190 секунд. Хранилище устроено в два уровня:
1. **RAM-голова (Tier 1):** в оперативной памяти крутятся только последние 32 секунды уже закодированного видеопотока.
2. **Дисковый кэш (Tier 2):** кадры старше 32 секунд сбрасываются во временные сегменты в системную папку `%TEMP%\Clippy\spool`. При выходе папка автоматически очищается.

| `VideoBitrateMbps` | Потребление RAM-головы (32 с) |
|---|---|
| 12 | ~40 МБ |
| 8 | ~27 МБ |
| 6 (по умолчанию) | ~20 МБ |
| 4 | ~13 МБ |

Короткий клип (F8, 30 с) вырезается **на 100% из RAM за 0.001 секунды**. Длинный (F9, 180 с) быстро склеивается из RAM и дискового SSD-кэша. Общее потребление памяти стабильно зафиксировано в районе ~50–120 МБ.

### Эффективность кодека HEVC (H.265)

Параметр `VideoCodec` в конфиге (и меню **Video Codec** в трее) позволяет переключаться между `hevc` (H.265, по умолчанию) и классическим `h264`.

Сравнение на реальной записи 1080p@53fps:

| Кодек и битрейт | Короткий клип (F8, 30 с) | Длинный клип (F9, 180 с) |
|---|---|---|
| H.264, 6 Мбит/с | 20.4 МБ | 120.3 МБ |
| HEVC, 6 Мбит/с | 18.4 МБ | 109.3 МБ |
| **HEVC, 3 Мбит/с** | **10.9 МБ** | **60.9 МБ** |

Благодаря кодеку HEVC трёхминутный ролик в превосходном качестве занимает всего **~60 МБ**, сохраняя кристальную чёткость картинки в динамичных сценах.

## Меню системного трея

Правый клик по иконке у часов открывает контекстное меню:

| Пункт меню | Назначение |
|---|---|
| **Open clips folder** | открыть папку с клипами в файловом менеджере по умолчанию (File Pilot, Total Commander, Проводник) |
| **Open logs folder** | открыть папку с отладочными логами |
| **Open Last Clip** | запустить самый свежий клип в плеере по умолчанию |
| **Open config.json** | открыть файл настроек в текстовом редакторе |
| **Short Clip Duration** | переключение длительности короткого клипа: 15 / 30 / 60 секунд |
| **Long Clip Duration** | переключение длительности длинного клипа: 1 / 2 / 3 / 5 минут |
| **Video Bitrate / RAM** | выбор битрейта: от 2 до 50 Мбит/с |
| **Video Encoder** | выбор энкодера: `nvenc_direct` (0-copy VRAM), `h264_nvenc` или `libx264` |
| **Video Codec** | выбор кодека: `HEVC (H.265)` или `H.264` |
| **Short Clip Hotkey** | независимый выбор горячей клавиши (F1–F12, NumPad 0–9) |
| **Long Clip Hotkey** | независимый выбор горячей клавиши (F1–F12, NumPad 0–9) |
| **Select Clips Folder...** | диалог выбора папки для клипов через системный проводник |
| **Clips Storage Limit** | квота дискового пространства: Unlimited / 10 / 20 / 30 / 50 ГБ |
| **Check for Updates** | проверка новой версии на GitHub и обновление в один клик |
| **Restart** | мягкий перезапуск Clippy |
| **Exit** | безопасное завершение работы |

Настройки применяются на лету, а файл `config.json` автоматически обновляется на диске.

## Системные требования

- **Операционная система:** Windows 10 (сборка 19041+) или Windows 11, разрядность x64.
- **Среда выполнения:** .NET не требуется (бинарник скомпилирован в чистый Native AOT).
- **Видеокарта:** NVIDIA GeForce (серии GTX 900+ / GTX 10xx / RTX) для аппаратного Direct NVENC (0-copy VRAM). На системах с графикой AMD/Intel при наличии внешнего ffmpeg доступен программный режим x264.
- **Библиотека мостика:** файл `clippy_nvenc.dll` входит в состав поставки и должен лежать рядом с `Clippy.exe`.
- **Звук:** Микрофон не требуется, запись ведётся с системного устройства вывода (то, что слышно в наушниках или динамиках).

## Ключи командной строки

В повседневном использовании запуск выполняется кликом по ярлыку. Для автоматизации и диагностики предусмотрены флаги:

| Ключ | Назначение |
|---|---|
| `--console`, `--debug` | запуск с окном консоли для просмотра живого лога |
| `--help`, `-h`, `--usage` | вывод справки по доступным ключам |
| `--record [секунды]` | запись видео в файл на фиксированное время |
| `--audio` | включение системного звука для режима `--record` |
| `--hotkeys` | включение обработки хоткеев для режима `--record` |
| `--tray`, `--minimized` | принудительный запуск в системном трее |
| `--encoder=ИМЯ` | переопределение видеоэнкодера на один запуск |
| `--fps-mode=РЕЖИМ` | режим частоты кадров: `passthrough` (по умолчанию) / `vfr` / `cfr` |
| `--export-at=С` `--export-dur=С` | автоматический срез клипа во время тестовой записи |
| `--smoke` | сквозной запуск проверки целостности подсистем |
| `--test-parsers`, `--test-ring`, `--test-mp4`, `--test-audio-timeline` | встроенные самотесты контейнеров и буфера |
| `--test-nvenc-native` | аппаратный тест 30 кадров через прямой NVENC в VRAM |

## Сборка из исходников

Для сборки проекта из исходного кода требуются .NET 10 SDK и Visual Studio 2022 Build Tools с компонентами C++ (для компиляции нативного мостика и Native AOT линковки):

```powershell
# 1. Компиляция C-мостика Direct NVENC
src\native\build.cmd

# 2. Публикация нативного бинарника
dotnet publish src/Clippy.csproj -c Release -r win-x64 -p:PublishAot=true -o publish
```

Готовый автономный дистрибутив формируется в каталоге `publish/`.
